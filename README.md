# 🌞 신재생에너지 마스터

신재생에너지발전설비기능사(**태양광**) 필기 학습도구입니다.
**개념 10단원 75섹션** + **적중예상문제 325문항**.
교재의 문제·보기·해설·그림을 그대로 옮겼고, 그림과 표는 원본 스캔을 잘라 그대로 씁니다.
**문항도 그림도 저장소에는 암호문으로만 올라갑니다.**

## 들어가는 법

| | 코드 | 기간 |
|---|---|---|
| 교사 | 도구 공용 문구형 암호 | 없음 |
| 학생 | 8자리 숫자 (도구 공용 주간 코드) | 그 주 월요일 ~ 다음 월요일 |

교사용으로 열면 **이번 주 학생 코드가 화면에 바로 뜹니다.** 코드표를 뒤질 필요 없습니다.
한 기기에서 한 번 열면 같은 주소의 다른 도구도 그냥 열립니다(`hong_pw_v1` 공용 키).

> 정적 호스팅에서는 화면에 비밀번호 칸만 두면 보호가 되지 않습니다(파일 주소를 직접 치면
> 그대로 받아짐). 그래서 문항 파일 자체를 **AES-GCM(PBKDF2-SHA256 20만 회)** 으로 암호화해
> `bank.enc` 로만 올리고, 브라우저에서 WebCrypto 로 실제 복호화합니다.
> **교재 그림 26장도 같은 내용키로 잠가 `enc/*.jpg.enc` 로만 올립니다.**
> 화면은 필요할 때 한 장씩 받아 풀어서 `blob:` 주소로 붙입니다.

## 화면

- **📚 개념** — 단원별 개념 정리. `🙈 빈칸으로 가리기`를 켜면 핵심어 512개가 빈칸이 되고,
  하나씩 눌러서 열어 볼 수 있습니다. 각 섹션 끝의 `✏️ 이 개념만 N문항 풀어보기`를 누르면
  방금 읽은 개념에 딸린 문항만 바로 풀립니다.
- **📖 배우기** — 정답과 해설을 처음부터 다 보여 줍니다. 단원별로 진도가 남습니다.
- **✏️ 연습 8문항** — 고르는 즉시 정답·해설. 파티클·흔들림 연출.
- **🏁 종합시험 20문항** — 전 단원에서. **푸는 동안 정답도 점수도 보이지 않습니다.**
  끝나면 오답노트(문제 그림·지문·내 답·정답·해설)가 나오고 그 아래 제출 버튼이 붙습니다.
- **📕 오답노트** — 틀린 문항이 쌓입니다. 연습에서 다시 맞히면 빠집니다.

### ⚠️ 개념 파트의 출처

교재의 **이론 본문(약 237쪽)은 스캔에 들어 있지 않습니다.** 그래서 개념 정리는
전사해 둔 325문항의 **해설과 도표**에서 뽑아 교재 표현 그대로 옮긴 것입니다.
이론에만 있고 문제에 나오지 않은 내용은 여기에 없습니다.
나중에 이론 쪽을 찍어 오면 그 위에 보강하면 됩니다.

## 고치는 법

```bash
# 1) 평문을 고친다 (전부 .gitignore — 절대 커밋 금지)
#    bank_book.js      문항
#    concept_book.js   개념  (표기법은 파일 머리말 참고)
#    img/              교재 그림 원본

# 2) 다시 암호화한다 (문항 + 개념 + 그림 + 빌드 표식을 한 번에)
python build_lock.py --pw <교사용 암호>

# 3) 암호문만 커밋한다
git add -A && git commit -m "문항 수정" && git push origin main
```

> **`img/` · `bank_book.js` · `concept_book.js` 는 이 저장소에 없습니다.** 작업하던 PC에만 있습니다.
> 다른 PC에서 고치려면 그 셋을 따로 옮겨 와야 합니다.
>
> 세 평문은 `require()` 로 읽으므로 **파일 끝에 `module.exports` 가 있어야 합니다.**
> 빠뜨리면 빌드가 조용히 `0문항`으로 지나갑니다(실제로 한 번 겪음).
>
> ⚠️ **캐시 함정** — 다시 빌드하면 내용키가 새로 생기는데, 브라우저가 옛 `enc/*.enc` 를
> 캐시에서 꺼내 쓰면 복호화가 조용히 실패해 **그림만 빈 칸으로** 보입니다.
> 그래서 빌드마다 표식을 `bank.enc` 에 넣고 그림 주소에 `?b=<표식>` 을 붙입니다.
> `<body data-build="…">` 로도 지금 올라간 빌드를 눈으로 확인할 수 있습니다.

`_weekly/secret.json`(저장소 밖)에 시크릿·기준일·접두어가 고정돼 있어
**다시 빌드해도 학생 코드는 바뀌지 않습니다.**

## 그림 다시 자르기

```bash
python crop.py <A|B|C> <쪽인덱스> <x0> <y0> <x1> <y1> <파일명.jpg>
```

좌표는 페이지 크기에 대한 비율(0~1)입니다. 회색조 JPEG로 저장돼 한 장당 10~90KB입니다.
`A`는 적중예상문제 PDF, `B`·`C`는 과년도 기출 PDF입니다(기출은 아직 미수록).

## 붙어 있는 공용 스크립트

`fx.js`(연출) — `FX.starsFor()` 는 점수가 아니라 **틀린 개수**를 받아 별 개수(0~3)를 돌려줍니다.
`rank.js` 의 `Rank.resultBox(res)` 는 **`Rank.award()` 가 돌려준 결과 객체**를 받아야 합니다.

`fx.js`(연출) · `rank.js`(계급) · `class-mode.js`(수업모드) · `reset.js`(기록 초기화) ·
`collector.js`(결과 제출). 제출은 교사별 링크의 `?rc=` 로 주소가 주입됩니다.
